Format-Hilfe (klicken zum Aufklappen) 
Ein Block = ein Termin. Blöcke mit einer Zeile  ---  trennen.

Erste Zeile = Kopf:   DATUM | SÄULE | TITEL      (nur Titel ist Pflicht)
   z.B.   2026-10-05 | P1 | Mythen über Solarförderung

Weitere Zeilen (alle optional, Reihenfolge egal):
   Hook: ...
   Idee: ...
   Variante: ...            (mehrfach möglich)
   Ziel: ...
   CTA: ...
   Ort: ...
   Equipment: a, b, c
   Aufgabe: Dreh @ 2026-10-01    (mehrfach; "@ Datum" optional)

Bestehenden Termin AKTUALISIEREN: Kopf mit vorhandener ID,
   z.B.   W10-Fr | Ergänzung ...    → angegebene Felder werden gemerged.

Schnell-Modus: einfach pro Zeile eine Idee (nur Titel, keine Doppelpunkte)
   → jede Zeile wird ein neuer Termin (Datum danach im Kalender anpassen).
